## 开发

```shell
git clone <your repo>/WorldmeMusic-mod
cd WorldmeMusic-mod
./gradlew clean build
```

仅支持 Fabric / Minecraft 26.2。构建产物位于 `worldme-fabric-26.2/build/libs/`。
